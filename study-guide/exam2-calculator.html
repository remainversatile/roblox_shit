How to get the table answer from the calculator

  1. Compute z, then round it to 2 decimals yourself.
  2. Type normalcdf(-1E99, z, 0, 1) and round the result to 4 decimals. That number is exactly what the z-table shows.
  3. For an area between two values, round each left area to 4 decimals before subtracting. That is why the key says .1865, not .1866.
  4. For 98% intervals and 98% sample sizes, type 2.33 into the formula by hand. ZInterval uses 2.3263 and can give a different answer.
  5. When a proportion problem says “round SE to 4 decimals,” use the rounded SE (.0273) in the z-score.

Canvas checks your typed number, and the professor builds answers with the table. When in doubt, do it the table way and use the exact calculator value only to catch arithmetic mistakes.

Where chapters get mixed up

The questions that look alike but need different formulas

One person or an average?

Ch 6 · one value\(z=\dfrac{x-\mu}{\sigma}\)
Ch 7 · sample mean\(\sigma_{\bar{X}}=\dfrac{\sigma}{\sqrt{n}}\)
\(z_{\bar{x}}=\dfrac{\bar{x}-\mu}{\sigma_{\bar{x}}}\)

Ch 6 wording: “a randomly selected goldfish”. Ch 7 wording: “the mean of a sample of 50”, “average balance of the sample”. A problem can describe a sample of 50 and still ask about one person.

Middle 95%: which one?

Ch 6 · individualsμ ± 1.96σ
Ch 8 · CI for μ\(\bar{x}\pm(1.96)\left(\dfrac{\sigma}{\sqrt{n}}\right)\)

Both use 1.96. The middle 95% of goldfish lifetimes centers on μ and uses σ. A 95% confidence interval centers on \(\bar{x}\) and uses the SE. The middle 95% of sample means (Ch 7) is μ ± 1.96σ/√n, centered on μ.

p, p̄, or p*?

Ch 7 · p known\(\sigma_{\bar{p}}=\sqrt{\dfrac{p(1-p)}{n}}\)
Ch 8 · p unknown\(\sqrt{\dfrac{\bar{p}\left(1-\bar{p}\right)}{\mathrm{n}}}\)

“66% of all adults over 70 use the internet” is p, so it's a Ch 7 probability. “In a sample of 87, 39% used temps” is p̄, so it's a Ch 8 CI. Sample size uses p* from a pilot, or .50 when there's no pilot.

z or t for a mean?

σ given → zPopulation SD, any n
Only s → tdf = n − 1, even when n = 60

Chapter 7 probability questions about \(\bar{x}\) always use z with σ. t only appears in Chapter 8 intervals. Sample size for a mean always uses z.

Which normality check?

Meansn ≥ 30, or the population is normal
Proportionsnp ≥ 5 and n(1 − p) ≥ 5

For a CI, check the counts with p̄. A small n is fine for a mean only when the problem says the population is normal (aerospace managers, n = 18).

“E” means two things

E( x̄ ), E( p̄ )Expected value = the center: μ or p
E aloneMargin of error = half the CI width

In the sample-size formulas, E is the margin. “Within 3 percentage points” means E = .03, not 3.

“x” means three things

Ch 6x = one raw value (80 days)
Ch 7–8 proportionsx = a count of successes, \(\bar{p}=\dfrac{x}{n}\)

And \(\bar{x}\) (with a bar) is a sample mean. If a proportion problem gives a count like “at least 210 of 300,” convert it to p̄ = 210/300 = .70 first.

Critical probability vs. critical value

Critical probabilityAreas: \(\frac{\alpha}{2}\) & \(1-\frac{\alpha}{2}\), e.g. .0250 & .9750
Critical valueThe z or t number: ±1.96

Read which one the blank wants. α itself is 1 − confidence (.05 for 95%).

Two tails or one?

Confidence intervalSplit α: upper-tail area α/2
“Lower-tail area .05”Look up .05 directly, don't halve it

The t-table practice asks both kinds. A lower tail gives a negative t (−1.676).

σ (÷N) vs. s (÷n − 1)

Populationσ, divide by N. TI: σx
Samples, divide by n − 1. TI: Sx

1-Var Stats shows both. Pick the one that matches whether the data are the whole population or a sample.

Rounding direction

Minimum nAlways UP: 43.01 → 44
Everything elseNormal rounding, to the decimals asked

The professor separates “round final answer only” from “round all calculations”. Read which one each question says.

Working backwards from a CI

Center\(\bar{x}\) or p̄ = (L + U)/2
MarginE = (U − L)/2, width = 2E

More confidence makes the interval wider. A larger n makes it narrower. Halving E takes 4 times the n, and 4 times the n halves the SE.

Calculator traps

  • invNorm wants the area to the LEFT. For “top 10%,” enter .90, not .10. On newer OS versions invNorm has a Tail setting, so make sure it's on LEFT.
  • 1-PropZInt needs a whole-number x. When you're given p̄ = .39 and n = 87, x = 33.93 causes an ERROR. Compute that CI by hand with the formula.
  • ZInterval and 1-PropZInt use exact z (2.3263 for 98%, 1.6449 for 90%). The table uses 2.33 and 1.645. Usually that only matters at 98%.
  • A sample-mean probability doesn't use σ in normalcdf. Enter σ/√n in the σ slot, or compute z first.
  • Missing parentheses: type 775/√(50), not 775/√50 followed by more operations. The TI keeps the √( open until you close it.
  • Percent inputs: enter proportions as decimals (.66). C-Level can be entered as 95 or .95.
  • Phone in your bag. Once LockDown Browser starts, the phone can't be your backup calculator, so bring batteries or a charge.

EXAM2.py: the Python program

Uses only the math module · tested against every Practice Test 2 answer, a full z-table, and t values for df 1–1000

Every result shows two lines. TABLE is the course method and matches the answer key. EXACT is the calculator method. If they disagree, enter the TABLE number unless the question says otherwise.

  • 0 · Which formula? (asks 2 questions)
  • 1 · P for one x (Ch 6)
  • 2 · P for x̄ (Ch 7, prints SE + CLT check)
  • 3 · P for p̄ (Ch 7, prints np checks)
  • 4 · Percent → cutoff for x, x̄, p̄, or μ
  • 5 · Critical z and t for any confidence
  • 6 · CI for μ with σ (z)
  • 7 · CI for μ with s (t, df, t-table column)
  • 8 · CI for p (from p̄ or a count x)
  • 9 · Min n, mean (σ or range/4)
  • 10 · Min n, proportion (pilot or .50)
  • 11 · From a CI: center, E, width
  • 12 · σ and s from raw data

Probability menus ask which area you want: below, above, between, outside, or within ±d of the center (the “within $100 of μ” type). Any number prompt accepts math such as 46/sqrt(85) or 1-.02/2. Bad input asks again instead of crashing.

Put it on the calculator

  1. Install TI Connect CE on your computer and connect the calculator by USB.
  2. Drag EXAM2.py onto the calculator in the Calculator Explorer. Program names are limited to 8 characters, and EXAM2 fits.
  3. On the calculator, open the Python app, choose EXAM2, and press Run.
  4. Answer the prompts. Press enter at [enter] to go back to the menu. Type q to quit.

# EXAM2 - MGSC 2301 Ch 6-8 helper
# Plain Python for the TI-84 Python app.
# Every answer shows TABLE (course z-table
# method, matches the key) and EXACT
# (full calculator precision).
# Inputs accept math: 46/sqrt(85), 1-.05/2
import math

# course table critical values
TBLZ = {80: 1.28, 90: 1.645, 95: 1.96,
        98: 2.33, 99: 2.576}
ENV = {"sqrt": math.sqrt, "pi": math.pi}


# ---------- input helpers ----------

def num(prompt, pos=False):
  while True:
    s = input(prompt).strip()
    if s == "":
      continue
    try:
      v = float(eval(s, ENV))
    except:
      print("Not a number. Try again")
      continue
    if pos and v <= 0:
      print("Must be > 0")
      continue
    return v


def pick(prompt, hi):
  # menu choice 1..hi
  while True:
    v = num(prompt)
    k = int(v)
    if k == v and 1 <= k <= hi:
      return k
    print("Pick 1 to", hi)


def prop(prompt):
  # proportion; 66 or .66 -> .66
  while True:
    v = num(prompt)
    if v > 1:
      v = v / 100
    if 0 < v < 1:
      return v
    print("Need 0 < p < 1")


def pause():
  input("[enter]")


def rnd(x, d):
  # half away from zero, float-safe
  m = 10 ** d
  s = 1
  if x < 0:
    s = -1
  return s * math.floor(abs(x) * m + 0.5 + 1e-9) / m


def r2(z):
  return rnd(z, 2)


def r4(a):
  return rnd(a, 4)


def f4(x):
  return "%.4f" % x


def f2(x):
  return "%.2f" % x


def pct(p):
  return "%.2f%%" % (p * 100)


# ---------- normal distribution ----------

try:
  _erf = math.erf
except:
  def _erf(x):
    # all-positive series, full precision
    sg = 1
    if x < 0:
      sg = -1
      x = -x
    if x > 6:
      return sg * 1.0
    term = x
    s = x
    k = 0
    while term > 1e-17 * s:
      k += 1
      term = term * 2 * x * x / (2 * k + 1)
      s += term
    return sg * 2 / math.sqrt(math.pi) * math.exp(-x * x) * s


def phi(z):
  # area to the LEFT of z
  return 0.5 * (1 + _erf(z / math.sqrt(2)))


def tphi(z):
  # table reading: z to 2 places, 4-place
  # area; past +/-3.49 reads .0000/1.0000
  z = r2(z)
  if z < -3.49:
    return 0.0
  if z > 3.49:
    return 1.0
  return r4(phi(z))


def invphi(a):
  lo = -9.0
  hi = 9.0
  for i in range(55):
    m = (lo + hi) / 2
    if phi(m) < a:
      lo = m
    else:
      hi = m
  return (lo + hi) / 2


def tablez(a):
  # z whose 4-place area is closest to a;
  # a tie (like .95) takes the midpoint
  best = 9.0
  zs = []
  z0 = r2(invphi(a))
  for i in range(-3, 4):
    z = r2(z0 + i / 100)
    d = abs(r4(phi(z)) - a)
    if d < best - 1e-9:
      best = d
      zs = [z]
    elif abs(d - best) <= 1e-9:
      zs.append(z)
  return rnd(sum(zs) / len(zs), 3)


# ---------- t distribution ----------

try:
  _lg = math.lgamma
except:
  def _lg(x):
    # Lanczos log-gamma
    c = [76.18009172947146, -86.50532032941677,
         24.01409824083091, -1.231739572450155,
         0.1208650973866179e-2,
         -0.5395239384953e-5]
    y = x
    tmp = x + 5.5
    tmp -= (x + 0.5) * math.log(tmp)
    s = 1.000000000190015
    for k in c:
      y += 1
      s += k / y
    return -tmp + math.log(2.5066282746310005 * s / x)


def _tiny(v):
  if abs(v) < 1e-30:
    return 1e-30
  return v


def _betacf(a, b, x):
  qab = a + b
  qap = a + 1
  qam = a - 1
  c = 1.0
  d = 1 / _tiny(1 - qab * x / qap)
  h = d
  for m in range(1, 200):
    m2 = 2 * m
    aa = m * (b - m) * x / ((qam + m2) * (a + m2))
    d = 1 / _tiny(1 + aa * d)
    c = _tiny(1 + aa / c)
    h *= d * c
    aa = -(a + m) * (qab + m) * x / ((a + m2) * (qap + m2))
    d = 1 / _tiny(1 + aa * d)
    c = _tiny(1 + aa / c)
    de = d * c
    h *= de
    if abs(de - 1) < 1e-10:
      break
  return h


def _ibeta(a, b, x):
  if x <= 0:
    return 0.0
  if x >= 1:
    return 1.0
  bt = math.exp(_lg(a + b) - _lg(a) - _lg(b)
                + a * math.log(x) + b * math.log(1 - x))
  if x < (a + 1) / (a + b + 2):
    return bt * _betacf(a, b, x) / a
  return 1 - bt * _betacf(b, a, 1 - x) / b


def tupper(t, df):
  # area to the RIGHT of t (t >= 0)
  return 0.5 * _ibeta(df / 2, 0.5, df / (df + t * t))


def invt(upper, df):
  # positive t with this upper-tail area
  lo = 0.0
  hi = 700.0
  for i in range(50):
    m = (lo + hi) / 2
    if tupper(m, df) > upper:
      lo = m
    else:
      hi = m
  return (lo + hi) / 2


# ---------- confidence helpers ----------

def getconf():
  while True:
    c = num("Confidence % (eg 95): ")
    if 0 < c < 1:
      c = c * 100
    if 0 < c < 100:
      break
    print("Need 0 to 100")
  a = 1 - c / 100
  print("alpha=" + f4(a) + " a/2=" + f4(a / 2))
  print("1-a/2=" + f4(1 - a / 2))
  return c


def zcrit(c):
  # (table z, exact z) for confidence c%
  up = 1 - (1 - c / 100) / 2
  ex = invphi(up)
  k = int(c + 0.5)
  if k in TBLZ and abs(c - k) < 1e-9:
    return TBLZ[k], ex
  return tablez(up), ex


def show_z(c):
  tb, ex = zcrit(c)
  print("z table " + str(tb) + "  exact " + f4(ex))
  return tb, ex


# ---------- probability engine ----------

def askkind():
  print("1 below a   2 above a")
  print("3 between a,b  4 outside a,b")
  print("5 within +/-d of center")
  return pick("Pick: ", 5)


def area(pa, pb, k):
  # pa, pb: left areas at a and b
  if k == 1:
    return pa
  if k == 2:
    return 1 - pa
  if k == 3:
    return pb - pa
  return 1 - (pb - pa)


def prob_core(ctr, se, se_t=0):
  # se_t: SE the table method uses
  if se_t == 0:
    se_t = se
  k = askkind()
  if k == 5:
    d = num("d (how far) = ", True)
    a = ctr - d
    b = ctr + d
    print("range " + str(rnd(a, 6)) + " to " + str(rnd(b, 6)))
    k = 3
  elif k >= 3:
    a = num("a (lower) = ")
    b = num("b (upper) = ")
    if b < a:
      a, b = b, a
  else:
    a = num("a = ")
    b = a
  za = (a - ctr) / se
  zb = (b - ctr) / se
  ta = r2((a - ctr) / se_t)
  tb = r2((b - ctr) / se_t)
  if k <= 2:
    print("z = " + f4(za) + " -> table " + f2(ta))
    print("left area " + f4(tphi(ta)))
  else:
    print("z(a)=" + f4(za) + " -> " + f2(ta))
    print("z(b)=" + f4(zb) + " -> " + f2(tb))
    print("areas " + f4(tphi(ta)) + ", " + f4(tphi(tb)))
  pt = area(tphi(ta), tphi(tb), k)
  pe = area(phi(za), phi(zb), k)
  print("TABLE P = " + f4(pt) + " (" + pct(pt) + ")")
  print("EXACT P = " + f4(pe))
  if k == 2:
    print("above = 1 - left area")
  if k >= 3:
    print("subtract AREAS, not z")
  if abs(ta) > 3.49 or abs(tb) > 3.49:
    print("z past 3.49: table edge")
  pause()


def clt(n):
  if n >= 30:
    print("n>=30: approx normal (CLT)")
  else:
    print("n<30: normal ONLY if pop is")


def phat_check(p, n):
  a = n * p
  b = n * (1 - p)
  print("np=" + f2(a) + " n(1-p)=" + f2(b))
  if a >= 5 and b >= 5:
    print("both >= 5: approx normal")
  else:
    print("NOT both >= 5: not normal!")
  se = math.sqrt(p * (1 - p) / n)
  print("SE = " + f4(se) + " (" + "%.6f" % se + ")")
  return se


def spread():
  # returns (center, se_exact, se_table)
  print("Value is about:")
  print("1 one x      2 sample mean")
  print("3 sample proportion")
  w = pick("Pick: ", 3)
  if w == 1:
    mu = num("mu = ")
    sg = num("sigma = ", True)
    return mu, sg, sg
  if w == 2:
    mu = num("mu = ")
    sg = num("sigma (population) = ", True)
    n = num("n = ", True)
    se = sg / math.sqrt(n)
    print("SE = sigma/sqrt(n) = " + f4(se))
    clt(n)
    return mu, se, se
  p = prop("population p = ")
  n = num("n = ", True)
  se = phat_check(p, n)
  return p, se, r4(se)

def ci_out(pt, e_t, e_e):
  dp = int(num("decimals wanted: "))
  if dp < 0 or dp > 6:
    dp = 2
  fm = "%." + str(dp) + "f"
  print("TABLE (" + fm % (pt - e_t) + ", " + fm % (pt + e_t) + ")")
  print("EXACT (" + fm % (pt - e_e) + ", " + fm % (pt + e_e) + ")")
  print("width = 2E = " + fm % (2 * e_t))
  pause()

def ceil_n(v):
  return int(math.ceil(v - 1e-9))


def m_n_mean():
  print("MIN n for a MEAN, round UP")
  print("1 sigma given  2 use range/4")
  k = pick("Pick: ", 2)
  if k == 2:
    rg = num("range (max-min) = ", True)
    sg = rg / 4
    print("sigma ~ " + f4(sg))
  else:
    sg = num("sigma = ", True)
  e = num("E (margin) = ", True)
  c = getconf()
  tb, ex = show_z(c)
  vt = (tb * sg / e) ** 2
  ve = (ex * sg / e) ** 2
  print("TABLE " + f4(vt) + " -> " + str(ceil_n(vt)))
  print("EXACT " + f4(ve) + " -> " + str(ceil_n(ve)))
  pause()


def m_n_prop():
  print("MIN n for a PROPORTION")
  print("no pilot: p* = .50, round UP")
  e = num("E (3 points = .03): ", True)
  if e >= 1:
    e = e / 100
    print("using E = " + str(e))
  ps = num("p* (0 = no pilot) = ")
  if ps <= 0:
    ps = 0.5
  elif ps >= 1:
    ps = ps / 100
  c = getconf()
  tb, ex = show_z(c)
  vt = tb * tb * ps * (1 - ps) / (e * e)
  ve = ex * ex * ps * (1 - ps) / (e * e)
  print("TABLE " + f4(vt) + " -> " + str(ceil_n(vt)))
  print("EXACT " + f4(ve) + " -> " + str(ceil_n(ve)))
  pause()

def m_sd():
  print("STD DEV from raw data")
  print("enter values, blank = done")
  xs = []
  while True:
    s = input("x" + str(len(xs) + 1) + " = ").strip()
    if s == "":
      break
    try:
      xs.append(float(eval(s, ENV)))
    except:
      print("Not a number")
  n = len(xs)
  if n < 2:
    print("need 2+ values")
    pause()
    return
  m = sum(xs) / n
  ss = 0.0
  for x in xs:
    ss += (x - m) ** 2
  print("n=" + str(n) + " mean=" + f4(m))
  print("sum(x-mean)^2 = " + f4(ss))
  print("POP sigma /N = " + f4(math.sqrt(ss / n)))
  print("SAMPLE s /(n-1) = " + f4(math.sqrt(ss / (n - 1))))
  pause()
