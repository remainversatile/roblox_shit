How to get the table answer from the calculator

  1. Compute z, then round it to 2 decimals yourself.
  2. Type normalcdf(-1E99, z, 0, 1) and round the result to 4 decimals. That number is exactly what the z-table shows.
  3. For an area between two values, round each left area to 4 decimals before subtracting. That is why the key says .1865, not .1866.
  4. For 98% intervals and 98% sample sizes, type 2.33 into the formula by hand. ZInterval uses 2.3263 and can give a different answer.
  5. When a proportion problem says “round SE to 4 decimals,” use the rounded SE (.0273) in the z-score.

Canvas checks your typed number, and the professor builds answers with the table. When in doubt, do it the table way and use the exact calculator value only to catch arithmetic mistakes.

Where chapters get mixed up

The questions that look alike but need different formulas

One person or an average?

Ch 6 · one value\(z=\dfrac{x-\mu}{\sigma}\)
Ch 7 · sample mean\(\sigma_{\bar{X}}=\dfrac{\sigma}{\sqrt{n}}\)
\(z_{\bar{x}}=\dfrac{\bar{x}-\mu}{\sigma_{\bar{x}}}\)

Ch 6 wording: “a randomly selected goldfish”. Ch 7 wording: “the mean of a sample of 50”, “average balance of the sample”. A problem can describe a sample of 50 and still ask about one person.

Middle 95%: which one?

Ch 6 · individualsμ ± 1.96σ
Ch 8 · CI for μ\(\bar{x}\pm(1.96)\left(\dfrac{\sigma}{\sqrt{n}}\right)\)

Both use 1.96. The middle 95% of goldfish lifetimes centers on μ and uses σ. A 95% confidence interval centers on \(\bar{x}\) and uses the SE. The middle 95% of sample means (Ch 7) is μ ± 1.96σ/√n, centered on μ.

p, p̄, or p*?

Ch 7 · p known\(\sigma_{\bar{p}}=\sqrt{\dfrac{p(1-p)}{n}}\)
Ch 8 · p unknown\(\sqrt{\dfrac{\bar{p}\left(1-\bar{p}\right)}{\mathrm{n}}}\)

“66% of all adults over 70 use the internet” is p, so it's a Ch 7 probability. “In a sample of 87, 39% used temps” is p̄, so it's a Ch 8 CI. Sample size uses p* from a pilot, or .50 when there's no pilot.

z or t for a mean?

σ given → zPopulation SD, any n
Only s → tdf = n − 1, even when n = 60

Chapter 7 probability questions about \(\bar{x}\) always use z with σ. t only appears in Chapter 8 intervals. Sample size for a mean always uses z.

Which normality check?

Meansn ≥ 30, or the population is normal
Proportionsnp ≥ 5 and n(1 − p) ≥ 5

For a CI, check the counts with p̄. A small n is fine for a mean only when the problem says the population is normal (aerospace managers, n = 18).

“E” means two things

E( x̄ ), E( p̄ )Expected value = the center: μ or p
E aloneMargin of error = half the CI width

In the sample-size formulas, E is the margin. “Within 3 percentage points” means E = .03, not 3.

“x” means three things

Ch 6x = one raw value (80 days)
Ch 7–8 proportionsx = a count of successes, \(\bar{p}=\dfrac{x}{n}\)

And \(\bar{x}\) (with a bar) is a sample mean. If a proportion problem gives a count like “at least 210 of 300,” convert it to p̄ = 210/300 = .70 first.

Critical probability vs. critical value

Critical probabilityAreas: \(\frac{\alpha}{2}\) & \(1-\frac{\alpha}{2}\), e.g. .0250 & .9750
Critical valueThe z or t number: ±1.96

Read which one the blank wants. α itself is 1 − confidence (.05 for 95%).

Two tails or one?

Confidence intervalSplit α: upper-tail area α/2
“Lower-tail area .05”Look up .05 directly, don't halve it

The t-table practice asks both kinds. A lower tail gives a negative t (−1.676).

σ (÷N) vs. s (÷n − 1)

Populationσ, divide by N. TI: σx
Samples, divide by n − 1. TI: Sx

1-Var Stats shows both. Pick the one that matches whether the data are the whole population or a sample.

Rounding direction

Minimum nAlways UP: 43.01 → 44
Everything elseNormal rounding, to the decimals asked

The professor separates “round final answer only” from “round all calculations”. Read which one each question says.

Working backwards from a CI

Center\(\bar{x}\) or p̄ = (L + U)/2
MarginE = (U − L)/2, width = 2E

More confidence makes the interval wider. A larger n makes it narrower. Halving E takes 4 times the n, and 4 times the n halves the SE.

Calculator traps

  • invNorm wants the area to the LEFT. For “top 10%,” enter .90, not .10. On newer OS versions invNorm has a Tail setting, so make sure it's on LEFT.
  • 1-PropZInt needs a whole-number x. When you're given p̄ = .39 and n = 87, x = 33.93 causes an ERROR. Compute that CI by hand with the formula.
  • ZInterval and 1-PropZInt use exact z (2.3263 for 98%, 1.6449 for 90%). The table uses 2.33 and 1.645. Usually that only matters at 98%.
  • A sample-mean probability doesn't use σ in normalcdf. Enter σ/√n in the σ slot, or compute z first.
  • Missing parentheses: type 775/√(50), not 775/√50 followed by more operations. The TI keeps the √( open until you close it.
  • Percent inputs: enter proportions as decimals (.66). C-Level can be entered as 95 or .95.
  • Phone in your bag. Once LockDown Browser starts, the phone can't be your backup calculator, so bring batteries or a charge.

# Built on the ECON2 menu and card layout.
# Plain ASCII, core Python, ti_draw; no external Python packages.
# Every calculation shows TABLE (course z-table method, matches the
# answer key) and EXACT (full calculator precision).
import math
try:
    import ti_draw as dr
    GRAPHICS = True
except ImportError:
    GRAPHICS = False
try:
    from ti_system import disp_clr
except ImportError:
    def disp_clr():
        print("\n" * 3)

# ---------- numbers ----------

TBLZ = {80: 1.28, 90: 1.645, 95: 1.96, 98: 2.33, 99: 2.576}
OK_CHARS = "0123456789.+-*/() "

def parse(s):
    # Numbers, a/b, and sqrt(), e.g. 46/sqrt(85)
    s = s.strip()
    for c in s.replace("sqrt", ""):
        if c not in OK_CHARS:
            raise ValueError("Use digits, / and sqrt()")
    try:
        return float(eval(s, {"sqrt": math.sqrt}))
    except ZeroDivisionError:
        raise ValueError("Zero denominator")
    except Exception:
        raise ValueError("Not a number")

def rnd(x, d):
    # half away from zero, float-safe
    m = 10 ** d
    sg = -1 if x < 0 else 1
    return sg * math.floor(abs(x) * m + 0.5 + 1e-9) / m

def f4(x):
    return "%.4f" % x

def f2(x):
    return "%.2f" % x

def short(x):
    return "%.6g" % x

def ceil_n(v):
    return int(math.ceil(v - 1e-9))

# ---------- normal and t distributions ----------

try:
    _erf = math.erf
except AttributeError:
    def _erf(x):
        # all-positive series, full precision
        sg = -1 if x < 0 else 1
        x = abs(x)
        if x > 6:
            return sg * 1.0
        term, s, k = x, x, 0
        while term > 1e-17 * s:
            k += 1
            term = term * 2 * x * x / (2 * k + 1)
            s += term
        return sg * 2 / math.sqrt(math.pi) * math.exp(-x * x) * s

def phi(z):
    # area to the LEFT of z
    return 0.5 * (1 + _erf(z / math.sqrt(2)))

def tphi(z):
    # table reading: z to 2 places, 4-place area
    z = rnd(z, 2)
    if z < -3.49:
        return 0.0
    if z > 3.49:
        return 1.0
    return rnd(phi(z), 4)

def invphi(a):
    lo, hi = -9.0, 9.0
    for i in range(55):
        m = (lo + hi) / 2
        if phi(m) < a:
            lo = m
        else:
            hi = m
    return (lo + hi) / 2

def tablez(a):
    # z whose 4-place area is closest to a; a tie takes the midpoint
    best, zs = 9.0, []
    z0 = rnd(invphi(a), 2)
    for i in range(-3, 4):
        z = rnd(z0 + i / 100, 2)
        d = abs(rnd(phi(z), 4) - a)
        if d < best - 1e-9:
            best, zs = d, [z]
        elif abs(d - best) <= 1e-9:
            zs.append(z)
    return rnd(sum(zs) / len(zs), 3)

try:
    _lg = math.lgamma
except AttributeError:
    def _lg(x):
        # Lanczos log-gamma
        c = [76.18009172947146, -86.50532032941677, 24.01409824083091,
             -1.231739572450155, 0.1208650973866179e-2, -0.5395239384953e-5]
        y = x
        tmp = x + 5.5
        tmp -= (x + 0.5) * math.log(tmp)
        s = 1.000000000190015
        for k in c:
            y += 1
            s += k / y
        return -tmp + math.log(2.5066282746310005 * s / x)

def _tiny(v):
    return 1e-30 if abs(v) < 1e-30 else v

def _betacf(a, b, x):
    qab, qap, qam = a + b, a + 1, a - 1
    c = 1.0
    d = 1 / _tiny(1 - qab * x / qap)
    h = d
    for m in range(1, 200):
        m2 = 2 * m
        aa = m * (b - m) * x / ((qam + m2) * (a + m2))
        d = 1 / _tiny(1 + aa * d)
        c = _tiny(1 + aa / c)
        h *= d * c
        aa = -(a + m) * (qab + m) * x / ((a + m2) * (qap + m2))
        d = 1 / _tiny(1 + aa * d)
        c = _tiny(1 + aa / c)
        de = d * c
        h *= de
        if abs(de - 1) < 1e-10:
            break
    return h

def _ibeta(a, b, x):
    if x <= 0:
        return 0.0
    if x >= 1:
        return 1.0
    bt = math.exp(_lg(a + b) - _lg(a) - _lg(b) + a * math.log(x) + b * math.log(1 - x))
    if x < (a + 1) / (a + b + 2):
        return bt * _betacf(a, b, x) / a
    return 1 - bt * _betacf(b, a, 1 - x) / b

def tupper(t, df):
    # area to the RIGHT of t (t >= 0)
    return 0.5 * _ibeta(df / 2, 0.5, df / (df + t * t))

def invt(upper, df):
    lo, hi = 0.0, 700.0
    for i in range(50):
        m = (lo + hi) / 2
        if tupper(m, df) > upper:
            lo = m
        else:
            hi = m
    return (lo + hi) / 2

def zcrit(c):
    # (table z, exact z) for confidence c percent
    up = 1 - (1 - c / 100) / 2
    ex = invphi(up)
    k = int(c + 0.5)
    if k in TBLZ and abs(c - k) < 1e-9:
        return TBLZ[k], ex
    return tablez(up), ex

# ---------- input ----------

def ask(label, positive=False, nonnegative=False):
    while True:
        disp_clr()
        print(label)
        print("Number, a/b, or sqrt()")
        print("Blank = cancel")
        s = input("> ").strip()
        if s == "":
            raise ValueError("Cancelled")
        try:
            x = parse(s)
            if positive and x <= 0:
                raise ValueError("Must be positive")
            if nonnegative and x < 0:
                raise ValueError("Cannot be negative")
            return x
        except ValueError as e:
            print(str(e))
            input("ENTER to retry")

def ask_p(label):
    # proportion: 66, 66% or .66 -> .66
    while True:
        p = ask(label + " (.66 or 66)", positive=True)
        if p > 1:
            p = p / 100
        if p < 1:
            return p
        disp_clr()
        print("Need 0 < p < 1")
        input("ENTER to retry")

def ask_conf():
    while True:
        c = ask("Confidence % (95 or .95)", positive=True)
        if c < 1:
            c = c * 100
        if c < 100:
            return c
        disp_clr()
        print("Need under 100%")
        input("ENTER to retry")

def choose(lines, n):
    # numbered submenu; returns 1..n or 0
    disp_clr()
    for line in lines:
        print(line)
    k = input("> ").strip()
    if k in [str(i) for i in range(1, n + 1)]:
        return int(k)
    return 0

# ---------- screen and cards (ECON2 layout) ----------

def wrap(text, width=28):
    lines, line = [], ""
    for word in text.split():
        if len(word) > width:
            raise ValueError("Display word too long")
        if line and len(line) + len(word) + 1 > width:
            lines.append(line)
            line = word
        else:
            line = word if not line else line + " " + word
    if line:
        lines.append(line)
    return lines

def ink(r, g, b):
    dr.set_color(r, g, b)

def card(title, body, frac=None):
    lines = body.split("\n") if isinstance(body, str) else body
    flat = []
    for line in lines:
        if not line:
            flat.append("")
        elif line[:1] == "!" and len(line) > 29:
            # keep every wrapped piece of an answer highlighted
            flat += ["!" + w for w in wrap(line[1:], 27)]
        else:
            flat += wrap(line)
    if len(flat) > (4 if frac else 8):
        raise ValueError("Card too tall: " + title)
    return (title, flat, frac)

def res(title, body, frac=None):
    # Result cards: anything too tall continues on extra pages.
    lines = body.split("\n") if isinstance(body, str) else body
    flat = []
    for line in lines:
        if line[:1] == "!" and len(line) > 29:
            flat += ["!" + w for w in wrap(line[1:], 27)]
        else:
            flat += wrap(line) if line else [""]
    room = 4 if frac else 8
    if len(flat) <= room:
        return [(title, flat, frac)]
    out = [(title, flat[:room], frac)]
    flat = flat[room:]
    while flat:
        out.append((title + " (cont)", flat[:8], None))
        flat = flat[8:]
    return out

RULES = ["", "left area", "1 - left area", "left(b) - left(a)", "1 - between"]
WORDS = ["", "Below a", "Above a", "Between a and b", "Outside a to b"]

def area(pa, pb, k):
    if k == 1:
        return pa
    if k == 2:
        return 1 - pa
    if k == 3:
        return pb - pa
    return 1 - (pb - pa)

def probability():
    w = choose(["1 One value x (Ch 6)", "2 Sample mean xbar (Ch 7)",
                "3 Sample prop pbar (Ch 7)", "0 Cancel"], 3)
    if not w:
        return
    if w == 1:
        ctr = ask("Population mean mu")
        se = ask("Population sigma", positive=True)
        se_t = se
        setup = res("Setup: one value", ["Center = mu = " + short(ctr),
                     "Spread = sigma = " + short(se), "No sqrt(n): one value."], ("z", "x - mu", "sigma"))
        sym = "x"
    elif w == 2:
        ctr = ask("Population mean mu")
        sg = ask("Population sigma", positive=True)
        n = ask("Sample size n", positive=True)
        se = sg / math.sqrt(n)
        se_t = se
        shape = "n >= 30: approx normal" if n >= 30 else "n < 30: pop must be normal"
        setup = res("Setup: sample mean", ["E(xbar) = mu = " + short(ctr), "!SE = " + f4(se), shape],
                     ("SE", short(sg), "sqrt(" + short(n) + ")"))
        sym = "xbar"
    else:
        ctr = ask_p("Population proportion p")
        n = ask("Sample size n", positive=True)
        se = math.sqrt(ctr * (1 - ctr) / n)
        se_t = rnd(se, 4)
        ok = n * ctr >= 5 and n * (1 - ctr) >= 5
        setup = res("Setup: sample prop", ["np = " + f2(n * ctr) + ", n(1-p) = " + f2(n * (1 - ctr)),
                     "Both >= 5: approx normal" if ok else "NOT both >= 5: not normal",
                     "!SE = " + f4(se) + " (table uses)", "Count given? use x/n"],
                     ("SE", "sqrt[ " + short(ctr) + "(" + short(1 - ctr) + ") ]", "sqrt(" + short(n) + ")"))
        sym = "pbar"
    k = choose(["1 Below a | 2 Above a", "3 Between | 4 Outside",
                "5 Within +/-d of center", "0 Cancel"], 5)
    if not k:
        return
    if k == 5:
        d = ask("Distance d from center", positive=True)
        a, b, k = ctr - d, ctr + d, 3
    elif k >= 3:
        a = ask("Lower value a")
        b = ask("Upper value b")
        if b < a:
            a, b = b, a
    else:
        a = ask("Value a")
        b = a
    za, zb = (a - ctr) / se, (b - ctr) / se
    ta, tb = rnd((a - ctr) / se_t, 2), rnd((b - ctr) / se_t, 2)
    cards = [setup, res("z for a", ["z = " + f4(za), "!Table z = " + f2(ta), "Left area = " + f4(tphi(ta))],
                         ("z", short(a) + " - " + short(ctr), f4(se_t)))]
    if k >= 3:
        cards.append(res("z for b", ["z = " + f4(zb), "!Table z = " + f2(tb), "Left area = " + f4(tphi(tb))],
                          ("z", short(b) + " - " + short(ctr), f4(se_t))))
    pt = area(tphi(ta), tphi(tb), k)
    pe = area(phi(za), phi(zb), k)
    ans = [WORDS[k] + " (" + sym + ")", "Rule: " + RULES[k], "!TABLE P = " + f4(pt),
           "EXACT P = " + f4(pe), "As percent: " + f2(pt * 100) + "%"]
    if k >= 3:
        ans.append("Subtract AREAS, not z.")
    if abs(ta) > 3.49 or abs(tb) > 3.49:
        ans.append("Past 3.49: table edge.")
    cards.append(res("Answer", ans))
    browse(cards)
    offer_graph(k, ta, tb, "P = " + f4(pt))

def cutoff():
    k = choose(["1 Bottom __% (below)", "2 Top __% (above)", "3 Middle __%", "0 Cancel"], 3)
    if not k:
        return
    pc = ask_p("Percent")
    lefts = [pc] if k == 1 else ([1 - pc] if k == 2 else [(1 - pc) / 2, 1 - (1 - pc) / 2])
    g = choose(["Solve for:", "1 Cutoff for one x", "2 Cutoff for xbar", "3 Cutoff for pbar",
                "4 Unknown mean mu", "0 Cancel"], 4)
    if not g:
        return
    if g == 4:
        x = ask("Known value x")
        sg = ask("Population sigma", positive=True)
    elif g == 3:
        ctr = ask_p("Population proportion p")
        n = ask("Sample size n", positive=True)
        se = math.sqrt(ctr * (1 - ctr) / n)
        se_t = rnd(se, 4)
    else:
        ctr = ask("Population mean mu")
        sg = ask("Population sigma", positive=True)
        se = sg
        if g == 2:
            n = ask("Sample size n", positive=True)
            se = sg / math.sqrt(n)
        se_t = se
    cards = []
    for a in lefts:
        cards.append(res("LEFT area " + f4(a), ["Find " + f4(a) + " INSIDE table.", "!Table z = " + str(tablez(a)),
                          "Calculator z = " + f4(invphi(a)), "Top __%: left = 1 - __."]))
    for a in lefts:
        zt, ze = tablez(a), invphi(a)
        if g == 4:
            cards.append(res("Unknown mean", ["mu = x - (z)(sigma)", "= " + short(x) + " - (" + str(zt) + ")(" + short(sg) + ")",
                              "!TABLE mu = " + f4(x - zt * sg), "EXACT mu = " + f4(x - ze * sg)]))
        else:
            cards.append(res("Cutoff", ["cutoff = center + (z)(SE)", "= " + short(ctr) + " + (" + str(zt) + ")(" + short(se_t) + ")",
                              "!TABLE = " + f4(ctr + zt * se_t), "EXACT = " + f4(ctr + ze * se),
                              "z < 0: cutoff below mean."]))
    browse(cards)
    zs = [tablez(a) for a in lefts]
    if k == 3:
        offer_graph(3, zs[0], zs[1], "Middle " + f2(pc * 100) + "%")
    else:
        offer_graph(k, zs[0], zs[0], WORDS[k].split()[0] + " " + f2(pc * 100) + "%")

# ---------- confidence intervals ----------

def ci_cards(est, e_t, e_e, dp, what):
    fm = "%." + str(dp) + "f"
    return res("Interval", ["!TABLE (" + fm % (est - e_t) + ", " + fm % (est + e_t) + ")",
                "EXACT (" + fm % (est - e_e) + ", " + fm % (est + e_e) + ")",
                "Width = 2E = " + fm % (2 * e_t), "We are confident the", what, "is in this interval."])

def ask_dp():
    d = int(ask("Decimals the question wants", nonnegative=True))
    return min(d, 6)

def interval():
    k = choose(["1 mu, sigma known (z)", "2 mu, only s given (t)", "3 p from pbar",
                "4 p from count x", "0 Cancel"], 4)
    if not k:
        return
    if k == 1:
        xb = ask("Sample mean xbar")
        sg = ask("Population sigma", positive=True)
        n = ask("Sample size n", positive=True)
        c = ask_conf()
        tb, ex = zcrit(c)
        se = sg / math.sqrt(n)
        cards = [res("Standard error", ["!SE = " + f4(se), "sigma known -> z"], ("SE", short(sg), "sqrt(" + short(n) + ")")),
                 res("Critical z", ["Confidence " + short(c) + "%", "!Table z = " + str(tb), "Calculator z = " + f4(ex)]),
                 res("Margin of error", ["E = (z)(SE)", "= (" + str(tb) + ")(" + f4(se) + ")", "!E = " + f4(tb * se), "Exact E = " + f4(ex * se)])]
        dp = ask_dp()
        cards.append(ci_cards(xb, tb * se, ex * se, dp, "population mean"))
    elif k == 2:
        xb = ask("Sample mean xbar")
        s = ask("Sample s", positive=True)
        n = ask("Sample size n (2+)", positive=True)
        if n < 2:
            raise ValueError("Need n >= 2")
        c = ask_conf()
        df = int(n - 1 + 0.5)
        up = (1 - c / 100) / 2
        te = invt(up, df)
        note("t-table lookup", ["Row: df = " + str(df), "Column: upper area " + f4(up), "!Exact t = " + "%.3f" % te,
             "n < 30: needs normal pop" if n < 30 else "t even though n >= 30", "Next: type YOUR table t."])
        tt = ask("Your table t (0 = exact)", nonnegative=True)
        if tt == 0:
            tt = rnd(te, 3)
        se = s / math.sqrt(n)
        cards = [res("Standard error", ["!SE = " + f4(se), "only s -> t, df = " + str(df)], ("SE", short(s), "sqrt(" + short(n) + ")")),
                 res("Margin of error", ["E = (t)(SE)", "= (" + short(tt) + ")(" + f4(se) + ")", "!E = " + f4(tt * se), "Exact E = " + f4(te * se)])]
        dp = ask_dp()
        cards.append(ci_cards(xb, tt * se, te * se, dp, "population mean"))
    else:
        if k == 4:
            x = ask("Count x", nonnegative=True)
            n = ask("Sample size n", positive=True)
            pb = x / n
        else:
            pb = ask_p("Sample proportion pbar")
            n = ask("Sample size n", positive=True)
        c = ask_conf()
        tb, ex = zcrit(c)
        se = math.sqrt(pb * (1 - pb) / n)
        ok = n * pb >= 5 and n * (1 - pb) >= 5
        cards = [res("Check + SE", ["pbar = " + f4(pb), "Counts " + f2(n * pb) + ", " + f2(n * (1 - pb)),
                      "Both >= 5: OK" if ok else "Counts < 5: not normal", "!SE = " + f4(se)],
                      ("SE", "sqrt[ " + f4(pb) + "(" + f4(1 - pb) + ") ]", "sqrt(" + short(n) + ")")),
                 res("Margin of error", ["Table z = " + str(tb) + " (exact " + f4(ex) + ")", "E = (z)(SE)",
                      "!E = " + f4(tb * se), "Exact E = " + f4(ex * se), "SE uses pbar (p unknown)."])]
        dp = ask_dp()
        cards.append(ci_cards(pb, tb * se, ex * se, dp, "population proportion"))
    browse(cards)

def sample_size():
    k = choose(["1 Mean, sigma given", "2 Mean, use range/4", "3 Proportion", "0 Cancel"], 3)
    if not k:
        return
    if k == 3:
        e = ask("Margin E (3 pts = .03)", positive=True)
        if e >= 1:
            e = e / 100
        disp_clr()
        s = input("Pilot p* (ENTER = .50): ").strip()
        ps = parse(s) if s else 0.5
        if ps >= 1:
            ps = ps / 100
        if not 0 < ps < 1:
            raise ValueError("Need 0 < p* < 1")
        c = ask_conf()
        tb, ex = zcrit(c)
        vt = tb * tb * ps * (1 - ps) / (e * e)
        ve = ex * ex * ps * (1 - ps) / (e * e)
        frac = ("n", "(" + str(tb) + ")^2 (" + short(ps) + ")(" + short(1 - ps) + ")", "(" + short(e) + ")^2")
        title = "Min n: proportion"
    else:
        if k == 2:
            sg = ask("Range (max - min)", positive=True) / 4
        else:
            sg = ask("Population sigma", positive=True)
        e = ask("Margin E", positive=True)
        c = ask_conf()
        tb, ex = zcrit(c)
        vt = (tb * sg / e) ** 2
        ve = (ex * sg / e) ** 2
        frac = ("n", "[ (" + str(tb) + ")(" + short(sg) + ") ]^2", "(" + short(e) + ")^2")
        title = "Min n: mean"
    browse([res(title, ["n = " + f4(vt), "!Round UP: " + str(ceil_n(vt)), "Exact z: " + str(ceil_n(ve)),
                         "Always round up."], frac)])
